Pathfinder is a simulation tool that allows users to create a grid-based map, place entities such as houses, hospitals, and ambulances, and simulate real-world emergency situations. The system uses graph-based pathfinding to find optimal routes for emergency services, while natural disasters and weather conditions can affect travel paths.

This project is useful for learning or demonstrating:
✔ Graph construction
✔ Pathfinding algorithms (e.g., BFS, Dijkstra, A*)
✔ Simulation design
✔ Event-driven systems
